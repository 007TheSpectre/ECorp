# Documentation du projet ECorp

## Arborescence des fichiers

Les PoC sont séparés par catégorie et par challenge  
Chaque PoC sont accompagné par un README expliquant :
- Sa description
- L'analyse de la vulnérabilité du challenge
- Une description du script
- Les résultats attendus du script
- Une remédiation de la faille

## Les challenges réalisés

Les challenges réussis sont les suivants :  

Stack :  
- Overflow
- Overwrite
- Environ
- Callback
- ret2func
- stackOverflow

Heap :  
- Heapfun
- HeapGot
- UseAfterFree

Format :  
- Overformat
- Tinkering
